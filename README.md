# ระบบแบบสอบถาม + Admin (Railway + PostgreSQL)

ระบบเดิมยังคงบันทึกคำตอบในตาราง `survey_results` เดิม โดยไม่ลบข้อมูลเก่า เพิ่มหน้า `/admin` สำหรับดูคำตอบภาษาไทย 10 ข้อ และดาวน์โหลดไฟล์ Excel `.xlsx` จริง

## ติดตั้งกับ Repository เดิม `foxyy88`

1. สำรองไฟล์ใน GitHub ก่อน แล้วอัปโหลด **ไฟล์ทั้งหมดภายในโฟลเดอร์นี้** ไปยังราก (root) ของ Repository เดิม `foxyy88` โดยแทนที่ไฟล์ชื่อเดิม (ไม่ต้องลบฐานข้อมูลหรือสร้าง Railway Project ใหม่)
2. Railway > `foxyy88` > **Variables** ตรวจสอบว่า `DATABASE_URL` ยังชี้ไปที่ `${{Postgres.DATABASE_URL}}`
3. เพิ่มตัวแปร `ADMIN_PASSWORD` เป็นรหัสผ่านที่ตั้งเอง **อย่างน้อย 12 ตัวอักษร** (ไม่ต้องส่งรหัสผ่านให้ใคร)
4. เพิ่มตัวแปร `SESSION_SECRET` เป็นข้อความสุ่มลับ **อย่างน้อย 32 ตัวอักษร** และไม่ใช้รหัสผ่านเดียวกับ ADMIN_PASSWORD (สร้างใน macOS Terminal: `openssl rand -hex 32`)
5. กด Apply/Deploy Changes หาก Railway ขอให้ยืนยัน และรอให้ทั้งบริการ `foxyy88` และ `Postgres` เป็น Online
6. ใช้โดเมน Railway ของเว็บไซต์เดิม เปิด `/admin` เช่น `https://<your-domain>.up.railway.app/admin`
7. เข้าด้วยรหัสผ่าน `ADMIN_PASSWORD` แล้วดูรายการ/คลิก "ดูคำตอบ" หรือ "ดาวน์โหลด Excel"

## ฟีเจอร์
- ระบบผู้ตอบแบบไม่ระบุตัวตน ไม่ต้องล็อกอิน
- หน้า Admin เข้าด้วยรหัสผ่าน และ Session Cookie แบบ HttpOnly, Secure, SameSite=Strict อายุ 8 ชั่วโมง
- ดูข้อมูลทุกครั้งที่ส่ง (แยกจากกันด้วย UUID) แสดงคำตอบ 10 ข้อเป็นภาษาไทย แบ่งหน้าละ 20 รายการ
- ดาวน์โหลด Excel `.xlsx` (สูงสุด 50,000 รายการต่อไฟล์) เป็นภาษาไทย
- ไม่เปลี่ยนโครงสร้างตารางเดิม ไม่ลบข้อมูลเก่า

## หมายเหตุด้านความปลอดภัย
- หน้า Admin และ API แสดงข้อมูลได้เฉพาะเมื่อเข้าสู่ระบบถูกต้อง อย่าเปิดเผย ADMIN_PASSWORD, SESSION_SECRET, DATABASE_URL
- เปิดเว็บไซต์ผ่าน HTTPS ของ Railway เท่านั้น เนื่องจาก Session Cookie ตั้งค่า Secure
- ใช้ rate limit สำหรับหน้าล็อกอินเบื้องต้นต่อ process และควรเปิดการป้องกันเพิ่มเติมที่ระดับแพลตฟอร์มสำหรับเว็บไซต์สาธารณะ
- บริการอาจมี log ของ IP ในระดับแพลตฟอร์มแม้ตารางคำตอบจะไม่เก็บชื่อ/IP
- โปรดตั้งค่า Backup และตรวจสอบค่าใช้จ่าย Railway
- ผลวิเคราะห์เป็นแนวโน้มเชิงสำรวจ ไม่ใช่แบบประเมินบุคลิกภาพมาตรฐาน

## ตรวจสอบโค้ด
`npm install` แล้ว `npm run check` และ `npm start` (ต้องกำหนด 3 ตัวแปรก่อน)
